# بیلتو

نمونه اولیه تعاملی فارسی برای مدیریت ساخت‌وساز. فایل `index.html` را در مرورگر باز کنید.

این نسخه فقط نمایشی است: ورود و پیامک واقعی، ثبت درخواست، پشتیبانی و اتصال به قیمت‌های روز یا سرور ندارد. پروژه‌ها در حافظه مرورگر همان دستگاه نگهداری می‌شوند و با پاک کردن داده‌های مرورگر حذف می‌شوند. قیمت‌ها و برآوردها نمونه‌اند و مبنای تصمیم مالی نیستند.
